# EHR × ブロックチェーン 結論検証ビューア

電子カルテ（EHR）とブロックチェーンに関する設計結論を、**外部資料で検証**し、検証ステータス付きの**インタラクティブ HTML** として可視化したプロジェクトです。

## 🌐 公開ページ

**<https://shuu5.github.io/EHR-blockchain/>**

スマホ・PC を問わず、URL だけで閲覧できます（インストール・ローカルサーバー不要）。

## 概要

`source/emr_blockchain_conclusion_verified.md`（電子カルテ × ブロックチェーンの最終結論整理）を題材に、次の 2 つを行いました。

1. **情報検証** — 文書の主張（外部事実 3 点 ＋ 結論 11 点）が正しいかを、2024–2026 年の研究・規制動向まで遡って調査し、裏付け／反証しました。
2. **可視化** — 検証ステータスバッジと出典リンクを埋め込んだ、オフラインでも開ける単一 HTML を構築しました。

## 機能（`site/index.html`）

- 外部事実 3 ＋ 結論 11 の検証カード（検証ステータスバッジ付き）
- 2 軸フィルタ（検証ステータス × 種別）
- インライン SVG アーキテクチャ図 3 点（要素ホバーで補足ツールチップ）
- 検証マトリクス 14 行
- 専門用語集 33 語 ＋ 本文用語のホバーツールチップ
- ライト／ダークテーマ（OS 追従 ＋ 手動切替）
- **依存ライブラリゼロ・単一ファイル・完全オフライン動作**

## ローカルで閲覧する場合

単一 HTML なので `site/index.html` をブラウザで直接開くだけでも動作します。一部ブラウザの `file://` 制限を避けたい場合は、簡易サーバー経由で開いてください。

```bash
python3 -m http.server 8765 --directory site
# → ブラウザで http://localhost:8765/ を開く
```

## 検証の原則・既知の制約

- 原典の情報源区分を尊重しています（「過去会話の記録」＝設計結論／「外部資料」＝検証済み事実）。
- 信頼度ラベルを区別: `verified`（一次資料）／ `deduced`（公式 docs）／ `inferred`（推測）／ `uncertain`。
- 原典に `[cite:10]`〜`[cite:32]` のマーカーがありますが参照文献リスト本体は含まれず、引用の完全トレースは不可能です。事実ベースの間接検証に留まります。

## 注意

本リポジトリは特定の設計議論の検証記録であり、医療情報システムの設計指針を提供するものではありません。実際の制度・ガイドラインは必ず一次資料（厚生労働省・各規制当局）で確認してください。
